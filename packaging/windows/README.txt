DND55 - Fantasy Tabletop RPG (5e 2024 rules, SRD 5.2.1)
=======================================================

Start:   double-click DND55.exe (or the DND55 Start Menu / desktop shortcut).
Saves:   %APPDATA%\DND55\campaigns.db   (portable version: the "data" folder next to DND55.exe)
Logs:    %APPDATA%\DND55\logs\          (send dnd55.log / crash-*.txt when reporting a problem)

Quick start
  1. Main menu > Create Campaign (you are the Dungeon Master) or Play - Quick Demo.
  2. Friends: Main menu > Join Campaign, paste the invite you got from the DM.
  3. The full tutorial is in WINDOWS_INSTALLATION_GUIDE.md (open it with Notepad or any browser).

Requirements: Windows 10 or 11 (64-bit), a GPU with DirectX 12 or Vulkan support
(most GPUs from 2015 on). If the game cannot start the graphics system, update your graphics
driver or choose another "Graphics backend" in Settings.
